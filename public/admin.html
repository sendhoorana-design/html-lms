Create exam

"No limit" still runs proctoring and logs every violation for you to review — it just never locks the student out automatically, no matter how many violations pile up.

Turn this off for practice-style or low-stakes exams — the timer and auto-grading still work, but nothing is monitored or logged, and students aren't forced into fullscreen.

Students can write HTML, CSS and JavaScript in separate tabs. Their files are combined into one page for auto-grading, so checks still work. Turn off for strict single-file exercises (e.g. practising the <style> tag).

Each check runs automatically when a student submits. Score = % of checks passed.

One check per line: type|label|value|extra — type is selector_exists, text_contains, or html_contains. For selector_exists, value is the CSS selector and extra is the min count (default 1). For text_contains, value is the text and extra is the word case to make it case-sensitive. For html_contains, value is the raw text to find in the source and extra is unused. Avoid using | inside your own values.

Header row required: type,label,value,extra — same meaning as the text format above, just comma-separated in a file instead of pasted.
